# Plugins

本仓库包含独立的 Codex 插件：

- [Codemao Sales](<Codemao Sales/README.md>)：编程猫家长异议的子智能体判断、个人弹药库导入和原文原图话术卡。
- [Agent Conductor 中文专家团](<Agent Conductor/agent-conductor-zh/README.md>)：中文专家角色路由与管理。

安装 Codemao Sales 时，请让 Codex 克隆本仓库到长期保留的本机目录，阅读并运行 `Codemao Sales/Install-CodemaoSales.ps1`。仅发送仓库链接不会自动执行安装。
