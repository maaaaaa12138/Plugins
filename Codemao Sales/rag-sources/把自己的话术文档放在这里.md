# 把自己的话术文档放在这里

`rag-sources/` 是 RAG 流程的源资料目录，放置个人话术 DOCX、图片及素材快捷方式。保留这份说明文件，把自己的资料放进同一文件夹即可。公开仓库不包含任何个人资料。

安装插件后，把自己的 DOCX 交给 Codex，并说“用这份文档作为我的话术资料”；导入 Skill 会整理并放到本机插件原件目录的这个文件夹。也可以将已符合格式的 DOCX 放在这里。话术卡只读取该目录顶层的 DOCX 文件，不扫描子文件夹。

本目录中的个人 DOCX 已被 Git 忽略，请不要手动上传话术文档。详细步骤见上一级 [README.md](../README.md)。
